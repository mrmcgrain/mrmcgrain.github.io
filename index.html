About Me

I'm a Full-Stack Software Engineer and Technical Instructor with more than 17 years of experience across software development, systems engineering, networking, infrastructure, and secure technology operations.

I build modern, accessible web applications using the MERN stack, with a focus on clean architecture, responsive design, RESTful APIs, WCAG 2.2 accessibility, and secure development practices. My work includes authentication and authorization, input validation, API security, CI/CD workflows, and deployment in Linux-based environments.

I also use AI-assisted development tools to improve productivity, accelerate problem-solving, and build practical solutions. I'm a strong advocate that AI is not a crutch nor replacement for our code, but a peer programmer. As an instructor and mentor, I enjoy helping others grow their technical skills while creating technology that supports businesses, learners, and meaningful community impact.
